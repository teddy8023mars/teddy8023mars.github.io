# teddy8023mars.github.io

My interactive 3D portfolio — a little low-poly studio you can poke around. **[Visit it live →](https://teddy8023mars.github.io)**

- Hand-built Three.js scene, no framework, no build step
- The cat on the desk watches your cursor — it's the same glTF model that lives on my real desktop in [DeskCat](https://github.com/teddy8023mars/DeskCat)
- Click the monitor / wall screen / whiteboard / cat to inspect each project
- 🌙 Day/night theme (follows your system, toggleable)
- Prefer no 3D? There's always a **Text version** button

Cat model: [Quaternius](https://quaternius.com/) (CC0). Everything else: mine.
